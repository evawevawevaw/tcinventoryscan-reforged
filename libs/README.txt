Put the Thaumcraft 4: Reforged jar here, named exactly as reforged_jar in gradle.properties
(default: thaumcraft-4-reforged-1.0-26.3.jar).
Build it from https://github.com/notlikethiss/thaumcraft-4-reforged with: ./gradlew build
The jar is in build/libs. Do not redistribute it: Reforged is personal-use only.
